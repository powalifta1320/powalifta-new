ABOUT
POWALIFTA.

POWALIFTA exists because powerlifting coaches still program in Excel and athletes still report on WhatsApp. Spreadsheets get lost. Threads get buried. Half-finished blocks pile up. Nobody has clean data on what actually got lifted.

It's one place to plan, train, and track. Coaches build week-by-week programs in a clean builder. Athletes open the app at the gym, see exactly what to do, tick each set, log how it felt on a 1–10 scale. That's it. Behind the scenes, every set turns into an estimated 1-rep max plotted over time, with variant multipliers (paused squat, tempo bench, deficit deadlift) handled automatically. Athletes set goals — squat / bench / deadlift / total / bodyweight — and watch the progress bars fill as the months roll. Coaches see all of it across their roster, in real time.

The pricing model: free for athletes, forever. Free for coaches with up to 3 athletes. Paid tiers as a roster grows. The free tier is real and permanent — it's not a trial. We make money when coaches make money.

Who's behind it

POWALIFTA is built by a powerlifter who got tired of spreadsheets. Reach out: powalifta1320@gmail.com.

What we believe

RPE over %1RM. Athletes know how a set actually felt. Trying to predict it from a max test from three weeks ago is a worse signal.

Variants matter. A paused squat at 140 isn't the same as a competition squat at 140. Multipliers exist for a reason.

Tools should disappear. The best logging app is the one you stop noticing. Tap, tick, log RPE, done.

Where it's going

Mobile polish, programming templates, comp prep mode with attempt selectors, self-serve data export, and a shared program library. If you have an idea, send it.
