How it works

Three roles. One platform.

Coach builds it. Athlete executes it. Strength tracked automatically.

01

Coach builds the program

Pick lifts (squat / bench / deadlift + variants), accessories, sets, reps and target RPE. Quick presets and a clean week-by-week builder.

02

Athlete trains, ticks, reports

Open today's session at the gym. Tick each set as you finish, log how it actually felt (RPE 1–10), done.

03

e1RM calculated, charts grow

Every working set becomes a data point. Estimated 1-rep max plotted over time per lift — variant multipliers handled automatically.
