Going live with the AI

Design (Part A) is already pushed and deploying. To switch the assistant on for real users, do these in order, then merge.

1. Anthropic console. Create an API key (ideally a dedicated key/workspace) and set a monthly spend cap. That cap is the hard backstop on cost.

2. Run the migration. In the Supabase SQL editor, run sql/migration-ai-chat-usage.sql (the per-user daily limit table).

3. Deploy the function. Create an Edge Function named ai-chat from edge-functions/ai-chat.ts, set its ANTHROPIC_API_KEY secret, and toggle Verify JWT ON.

4. Merge & push. Merge ai-chat into main (drop review.html first — it's dev-only) and push. The assistant goes live; until the function exists it safely falls back to mock.

The Anthropic key only ever lives in the edge function's secrets. It is never in the repo and never in the browser, so it can't leak through the client.
